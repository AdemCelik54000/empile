═══════════════════════════════════════════════════════════════════════════════
                        PROCHAINES ÉTAPES À FAIRE
═══════════════════════════════════════════════════════════════════════════════

ÉTAPE 1: CRÉER LES URLs OBLIGATOIRES (30 min)
─────────────────────────────────────────────
Voir: AppStore/URLs-Setup.md

Tu dois créer 2 pages:
   1. Privacy Policy: https://example.com/empile/privacy
   2. Support Page: https://example.com/empile/support

+ Créer une adresse email de support: empile.support@example.com

Options rapides:
   - GitHub Pages (gratuit, facile)
   - Netlify (gratuit, simple)
   - Ton propre site web

ÉTAPE 2: CRÉER LES SCREENSHOTS (30 min)
────────────────────────────────────────
Voir: AppStore/ScreenshotGuide.md

1. Lancer Empile dans le simulateur
2. Capturer 6 screenshots de gameplay différents:
   ✓ Menu/titre
   ✓ Tutoriel
   ✓ Gameplay actif
   ✓ Effet vent
   ✓ Score élevé
   ✓ Leaderboards Game Center

3. Redimensionner:
   iPhone: 1242 × 2688
   iPad: 2048 × 2732

ÉTAPE 3: ALLER SUR APP STORE CONNECT (15 min)
──────────────────────────────────────────────
https://appstoreconnect.apple.com

1. Créer une nouvelle app:
   - Bundle ID: app.empile.Empile
   - Nom: Empile
   - Catégorie: Games > Puzzle

2. Remplir les métadonnées:
   - Utiliser le texte de AppStore/AppStoreMetadata.md
   - Ajouter tes URLs réelles
   - Uploader les screenshots

3. Définir l'âge: 4+ (All Ages)

ÉTAPE 4: ARCHIVER ET UPLOADER (15 min)
────────────────────────────────────────
1. Dans Xcode:
   Product → Archive

2. Cliquer "Distribute App"
   → App Store Connect
   → Upload

3. Attendre le traitement (~5-10 min)

ÉTAPE 5: SOUMETTRE POUR RÉVISION (5 min)
──────────────────────────────────────────
Dans App Store Connect:
   → Click "Submit for Review"
   → Répondre aux questions de révision
   → Confirmer

═══════════════════════════════════════════════════════════════════════════════
                        SI REJETÉ PAR APPLE
═══════════════════════════════════════════════════════════════════════════════

Si Apple refuse l'app:
   1. Lire ATTENTIVEMENT la raison de rejet
   2. Fixer le problème
   3. Incrémenter le build number (1 → 2)
   4. Upload le nouveau build
   5. Resubmit avec note expliquant la fix
   6. Reattendue (24-48h)

Rejets courants (à éviter):
   ❌ Nom d'app trompeur
   ❌ Descriptions trompeuses
   ❌ Crashes au démarrage
   ❌ Privacy policy manquante
   ❌ Gameplay différent des screenshots
   ❌ Code de débogage laissé
   ❌ Contenu offensif
